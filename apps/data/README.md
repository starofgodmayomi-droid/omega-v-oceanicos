# Data

Shared data directory for the OCEANICOS applications. This directory holds
file-based stores, seed data, and fixture files used by the API and web app
during local development.

## Contents

The directory is currently a placeholder for shared data assets. Files placed
here are consumed by the API's file-based SQLite persistence layer and by
development-time seed scripts.
