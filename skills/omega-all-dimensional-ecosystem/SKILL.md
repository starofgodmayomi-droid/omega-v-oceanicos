# Omega All-Dimensional Ecosystem

## Law

Work inside this repository. Do not open a second product or an unbounded simulation in order to hold every dimension.

```text
Ω∞v = VERIFY(Δ(Intent, Reality))
NEXT = argmax_{Δ in A}  E[Verified Value(Δ)] / (Risk(Δ) + Cost(Δ) + ε)
```

`ε` is a positive constant so a zero-cost proposal cannot divide by zero. It is not a measured physical constant. `A` is the set of candidates that already passed bounds, policy, privacy, and AUTHORITY. A candidate outside `A` is not ranked.

Expectation is not an observation. `E[Verified Value]` stays an estimate until a check runs. The numerator is observed verified value only when evidence is `VERIFIED` and the acceptance criterion was met.

## All dimensions, finite

Every layer below is a representation. None of them is automatic AUTHORITY, and none of them is reality.

| Axis | Finite form | Until observed |
| --- | --- | --- |
| 0D | No allocation. Empty scope. | `NOT_EXECUTED` |
| 1D–3D | Coordinates with units, origin, and handedness. | `UNKNOWN` |
| 4D | A named tick, commit, or clock, with a timezone when a clock is the source. | `UNKNOWN` |
| N-D | An array with declared rank, shape, dtype, and bounds. | `UNKNOWN` as a metaphysical claim |
| Ecosystem | The repositories, packages, skills, apps, and checks that were actually opened. | `UNKNOWN` for anything not opened |
| ∞ | Another bounded pass with a stop, a budget, and a handoff. | `NOT_EXECUTED` until admitted |

Do not allocate an infinite array. If rank or bounds are missing, use the smallest shape that can answer the request and label the assumption. Coordinate, shader, and matrix detail stays in `skills/oceanicos-max-space-full-stack`. The kernel sequence stays in `skills/omega-v-os`.

## Selection is not execution

1. OBSERVE current reality: branch, head, and the files the delta would touch. Do not invent green checks.
2. Name Intent and Reality separately. `Ω∞v` is that comparison, not a mood.
3. List candidates. Mark each `ALLOW`, `REVIEW`, or `DENY`.
4. Reject anything unbounded, already applied, or missing rollback.
5. Rank only `ALLOW` candidates by the ratio above. Break ties by safety reduction, then by closing an evidence gap, then by reversibility, then by lower maintenance.
6. Execute at most the selected delta, and only when the user asked for the change and it is reversible.
7. OBSERVE again. Label the result `VERIFIED`, `DIVERGENT`, `UNKNOWN`, or `NOT_EXECUTED`.

`POSSIBLE` is not done. A `REVIEW` candidate is held, not executed. `DENY` is not ranked. A high estimate does not create AUTHORITY.

## What this pass does not claim

Deployment, cloud, merge, production health, income, and totality stay `NOT_EXECUTED` unless this session observed them. A skill file is not a skill followed. Selection is not execution. Reality remains the final evaluator.
