# @oceanicos/authorization

Constitution Layer: **Group C — Security**

## Mission
Implements fail-closed human authorization gates and cryptographic credential verification for all consequential system actions per Constitution §6, §8, and §9.

### Key Invariants
- `KEY ≠ AUTHORITY`
- `SIGNATURE ≠ AUTHORIZATION`
- `INTELLIGENCE ≠ AUTHORITY`
- Actions classified as destructive, financial, or irreversible strictly require verified human steward DID authorization.
