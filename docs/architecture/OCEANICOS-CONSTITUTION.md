## Memory and conversation boundary

“Whole memory + whole conversation” is treated as a **provenance design requirement**, not as permission to collect everything or a claim that all context is currently unified. A future memory integration must preserve, for every meaningful record:

```text
WHAT WAS OBSERVED
WHAT EVIDENCE EXISTED
WHAT WAS INFERRED
WHAT WAS AUTHORIZED
WHAT WAS EXECUTED
WHAT ACTUALLY HAPPENED
WHAT WAS VERIFIED
WHAT DIVERGED
WHAT REMAINS UNKNOWN
WHAT CHANGED
WHY IT CHANGED
WHO / WHAT AUTHORIZED IT
WHAT PROVENANCE CONNECTS IT
```

The following boundaries are mandatory:

- Memory preserves lineage; it does not manufacture truth.
- Conversation context is not automatically a consent record, authority grant, or permanent personal profile.
- Inference must remain marked as inference and must not become an observed fact by compression.
- Sensitive information must be minimized, purpose-bound, access-controlled, revocable where applicable, and retained only under an explicit policy.
- Historical memory must not silently override current human intent or current reality.
- A memory lookup may inform a proposal; only normal policy, authority, admission, and execution gates may permit a consequential action.

