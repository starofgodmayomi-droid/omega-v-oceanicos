# KAI — The Current That Remembers

KAI is the continuity layer over the existing Ω∞v memory and verification fabric.

## Contract
- MEMORY != PROOF
- CAPABILITY != AUTHORITY
- DOCUMENTATION != EVIDENCE
- SIMULATION != REALITY
- UNKNOWN is preserved.
- Corrections are new Drops with explicit lineage.

## Runtime bridge
Observer -> Verification -> Remember -> KAI -> next Δ

KAI consumes persisted Mini Blocks. PASS becomes VERIFIED; DIVERGENT/FAIL remains DIVERGENT; unclassifiable evidence remains UNKNOWN.

KAI does not create evidence. An UNKNOWN Drop is explicitly non-persisted until an admissible observation/evidence path exists.

## Authority boundary
KAI reports continuity and provenance. It does not authorize execution, mutation, merge, deployment, or external-world outcomes.

REALITY > OBSERVATION > EVIDENCE > VERIFICATION > MEMORY
